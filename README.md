# 현장수첩 📐 — 도장 공수 · 자재 · 견적 · 장부 관리

도장(페인트) 사업자를 위한 올인원 현장 앱입니다. 폰에 설치해서 오프라인으로 씁니다.

## 뭘 할 수 있나요

| 탭 | 기능 |
|---|---|
| 📐 **현장** | 가로·세로·층고 실측 → 해배(㎡), 페인트 말 수, 퍼티 포 수, 공수, 견적 금액 자동 계산. 현장 사진 첨부, 실측서 인쇄·PDF |
| 🧾 **견적서** | 현장 계산 결과로 견적서 자동 생성, 항목 편집, 부가세 토글, 인쇄·PDF·텍스트 복사, 완료된 공사는 버튼 한 번으로 장부에 매출 기록 |
| 🗓 **달력** | 공수 달력 — 내 현장 / 일당 / 반공수 / 휴무 기록, 드래그로 기간 입력, 월 공수·수입 집계 |
| 💰 **장부** | 수입·지출 기록(증빙 유형별), **부가세 예상 납부세액**(반기별 매출세액−매입세액), **종소세 예상 세액**(누진세율·지방세·3.3% 기납부 반영), **세금계산서 발행 대장**(손택스 입력용 복사) |
| ⚙️ **설정** | 일당·자재 단가·소모량 기준, 사업자 정보, **전체 데이터 백업/복원(JSON)** |

- 달력에 적은 일당·수입은 장부 탭에서 **"달력 수입 가져오기"** 버튼으로 한 번에 옮겨져요 (중복 방지).
- 세금계산서는 법적으로 홈택스(손택스)에서만 발행되므로, 이 앱은 **발행 정보 복사 + 발행 대장 관리**를 맡아요.
- 부가세·종소세 숫자는 **참고용 추정치**입니다. 실제 신고는 홈택스에서, 금액이 크면 세무사 상담을 받으세요.

## 데이터는 어디 저장되나요

전부 **내 폰(브라우저 localStorage)** 에만 저장됩니다. 서버로 전송되지 않아요.
폰을 바꾸거나 브라우저 데이터를 지우면 사라지니, **설정 탭 → 백업 파일 저장**을 한 달에 한 번은 해두세요.

## 배포하기 (한 번만 하면 돼요)

1. GitHub 저장소 → **Settings → Pages → Source**를 **GitHub Actions**로 선택
2. 이 저장소에 푸시하면 자동으로 빌드·배포됩니다 (`.github/workflows/deploy.yml`)
3. 배포 주소: `https://<계정이름>.github.io/Paint-app/`

## 폰에 설치하기

배포 주소를 폰 브라우저로 연 뒤:

- **아이폰**: Safari → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome → 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치")

설치하면 일반 앱처럼 아이콘으로 실행되고, 인터넷이 안 터지는 현장에서도 열립니다.
